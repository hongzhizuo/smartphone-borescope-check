# Smartphone borescope check

A one-page check for a 6 mm smartphone borescope with a 1 m cable and a tip that bends both ways.

Set the hole diameter, the distance, the bend, what is on the screen, and whether the part is hot or the handle would get wet. The page answers only "Look first" or "Take it apart", and lists which checks passed.

Open `index.html` in a browser. No install and no build.

The page does not name a fault, and it does not link to a shop.
